# Smart Plant Diagnosis System 🌱

An AI-powered Smart Plant Diagnosis System developed using Deep Learning techniques to detect plant diseases from leaf images. The system helps farmers identify crop diseases early and provides suitable treatment recommendations to improve agricultural productivity.

## Features

- Plant Disease Detection
- Image-Based Diagnosis
- Supports Multiple Crops
- Disease Prediction with Confidence Score
- Fertilizer & Treatment Suggestions
- User-Friendly Interface

## Technologies Used

- Python
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- OpenCV
- NumPy
- Streamlit / Flask

## Supported Crops

- Sugarcane
- Paddy
- Maize

## Project Workflow

1. Upload plant leaf image
2. Image preprocessing
3. Disease prediction using CNN model
4. Display disease name and confidence score
5. Provide treatment recommendations

## Applications

- Smart Farming
- Early Disease Detection
- Agricultural Monitoring
- Crop Health Management

## Future Enhancements

- Mobile Application Integration
- Real-Time Camera Detection
- More Crop Support
- Multilingual Farmer Assistance

## Project Description

This project was developed to assist farmers and agricultural sectors by using Artificial Intelligence for automatic plant disease detection. The system analyzes leaf images and predicts diseases accurately using Deep Learning models.
